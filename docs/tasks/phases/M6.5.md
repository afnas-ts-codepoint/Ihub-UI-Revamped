## Exact currency contract

KWD per currency unit: KWD `1`, USD `0.307`, EUR `0.334`, AED `0.0836`, SAR `0.0819`, GBP `0.392`.

Input commas are removed, `parseFloat` is applied, finite values are multiplied by the selected rate, and display uses `en-US` grouping with exactly three decimals. Blank/invalid input displays blank; zero displays `0.000`. No live rates or FX dependency exists.
