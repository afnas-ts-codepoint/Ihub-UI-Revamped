# M11.3 — Dashboard configuration runtime integration

Status: Pending

Owner: Not assigned

Reviewer: Not assigned

Depends On: M11.2, M8.2, M10.2

## Objective

Connect the approved prototype-faithful Settings configuration builders to the completed Task and Overview dashboard runtime after their stores and widgets exist.

## Scope

- Write approved configuration changes to `taskDashboardConfig.store`.
- Apply Default, Role, Department and User inheritance to the completed dashboards.
- Update the completed Tasks and Overview dashboards live without changing the approved M11.2 Settings UI.

## First-release treatment

Deferred. The first release requires the prototype-visible Settings experience from M11.1 and M11.2, using local/mock state. This task belongs to the continuing full migration and must not block that scoped release.

## Must Not

- Do not redesign or over-polish the approved M11.2 interface.
- Do not begin until M8.2 and M10.2 are completed and approved.
- Do not add backend persistence or authorization unless separately approved.

## Acceptance Criteria

- Saved configuration updates the completed Tasks and Overview dashboards live.
- Scope inheritance and widget limits remain consistent with the approved M11.2 behavior.
- Existing M11.2 visual and behavior tests remain green.

## Quality Gates

Run every Phase 3 gate active and applicable at this phase, record the results, move the task to Review, and stop for human approval.
