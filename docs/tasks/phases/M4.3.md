## Delivered behavior

### Shared file readers

- `shared/file/xlsx.ts` lazily executes `import('xlsx')`, opens the workbook, selects its first sheet and returns a simple row grid using `sheet_to_json({ header: 1, blankrows: false })`.
- A distinct `SpreadsheetReaderLoadError` preserves the prototype’s exact “reader did not load” path; parse and FileReader failures use the prototype’s general unreadable-file message.
- `shared/file/readFile.ts` recognizes `.xlsx`, `.xls`, `.xlsm` and `.xlsb` case-insensitively, reads them as `ArrayBuffer`, and routes every other selected file through the prototype text path. It adds no backend, progress or speculative upload framework.
- The hidden file input resets immediately after selection, so selecting the same file again triggers another import.

### Masters `domain/bulkNames`

- Spreadsheet: only column zero of the first sheet contributes names; additional columns are ignored.
- CSV/text: values are flattened with the exact prototype `/[\r\n,;]+/` split and one leading/trailing quote strip; this intentionally is not an RFC CSV parser.
- Values are stringified, trimmed at the edges, and blank/whitespace-only values are dropped. Internal spaces are preserved.
- Only the first remaining value is eligible for case-insensitive header stripping.
- Project Category headers: `name`, `names`, `category name`, `project category`, `project category master`.
- Sub Area headers: `sub area`, `sub areas`, `subarea`, `subareas`, `name`, `names`.
- Existing nonblank editable rows remain first; imported names append. Stable de-duplication is exact and case-sensitive, so `Alpha` and `alpha` remain distinct. Blank starter rows disappear when valid names arrive.
- Imported rows remain editable/removable, retain the responsive four-column prototype grid and can be extended with Add more.

### Dialog integration and visible text

- Project Category exposes `Sample CSV` and `Upload records`.
- Sub Area exposes `Upload Excel` plus the exact `.xlsx` first-column hint; it intentionally has no sample-download control.
- Project Category accepts `.csv,.xlsx,.xls,.xlsm,.xlsb` plus the prototype MIME hints. Sub Area accepts the same extensions in its prototype order.
- Success messages are exactly `N records added from {filename}` and `N sub areas added from {filename}`. `N` is the cleaned parsed count after header removal but before merge de-duplication.
- Empty valid input leaves rows unchanged and shows exactly `No records found in that file.` or `No sub areas found in that file.`
- Reader/parser failure shows exactly `That file could not be read.`
- Lazy-module load failure shows exactly `The spreadsheet reader did not load — refresh the page and try again.`
- Every note, including errors, uses the prototype’s green `ok` chip. EN/AR strings match the source; Arabic/RTL ordering and filename placement were verified visually.
