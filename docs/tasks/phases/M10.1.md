## Review Findings

**Delivered behaviour.**

- `/home/approvals`: ranked queue (`rankQueue` = score order, pinned first), group chips with live counts that ignore the selection (`other` has no chip), select-all/clear keyed on the whole selection, batch bar, empty state; ActionCard with stripe, reference code, priority/due/SLA chips, Edit (= body click), Send back, Reject, Pin, Approve|Verify; phone layout (≤760px) with the action rail on a bottom row.
- Decisions: approve removes the item and opens the track prompt (not after reject, send back or batch); reject records the rejected feed; send back without a reason opens the dialog, an empty-string reason from an embedded form skips it; escalate forces critical/today without touching the `due` text; batch acts on the whole selection (including ids hidden by the filter).
- Workflow drawer (action, incident, job-order bodies; Escape/scrim close; inline-end side) and Form Preview dialog (action sheet, petty cash, budget summary). Budget kinds need no budgeting component, so no home → budgeting dependency was added.
- Domain/golden: `scoreAction`, `scoreIncident`, `rankActions`, SLA state/labels, severity ladder and reference codes match values executed against the prototype code (identical in the root and `ihub` files).

**Preserved prototype quirks.** Drawer shows a stale snapshot after escalate/pin; second Pin from the same snapshot re-tracks yet unpins; incident "Resolve" fires `dismiss`; job-order Dismiss leaves the drawer open and Assign overwrites any status; resubmit only clears the tracker row; verify only changes captions; History text and ACTIONS data are English-only; Pin/Escalate/Close/"Current step"/"SLA" captions are English in Arabic; the Form Preview forms are blank (not prefilled). See `PROTOTYPE_NOOPS.md`.

**Excluded as dead source.** In-drawer "Form preview"/`showForm`, `headTone`, `sheet` HUD kind, `assignedTab`, `RecommendedNextAction.setView`, `view === 'joborders'`.

**Corrections to approved work (for the reviewer).** `ActionSheetForm` (M6.6) now always has the 40px bottom padding and a sticky right column, as `CreateActionSheetPanel` does; the prototype's review/resubmit/verify paths there were audited and fixed (reason chips unstyled, missing icon, send-back panel styling, English reason category).

**Decision (approved with M10.1).** `PettyCashRequestCreate` review/resubmit/verify/onDecision were ported (supersedes M6.7 Option A for Home) — see `DECISIONS.md`.
