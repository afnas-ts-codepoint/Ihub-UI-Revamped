## StatTile

`src/shared/ui/stat/StatTile.tsx` is domain-agnostic: it accepts `label`, `value`, an optional `sub`, and an optional `tone` (`'ok' | 'bad' | 'neutral'`, default `neutral`). It owns only generic presentation (card, eyebrow-style label, large numeric value with tone color, optional supporting text) and has no Overtime-specific business meaning. Its only M3.3 consumer is the Overtime screen's three stat cards; no speculative variants were added.

## Shared table reuse

`TabbedTable` and `TablePagination` are reused unchanged in behavior. One minimal, generic type widening was made to `TableColumn<Row>.key` (from `keyof Row` to `keyof Row | (string & {})`) so a `render`-only column with no corresponding data field — the Overtime actions column — can be expressed without misusing an existing field key. This is a type-level change only: the fallback `String(row[column.key])` path (used only when a column has no `render`) was updated to a safe cast; no runtime behavior changed for the existing Appraisal consumer, and a new shared-table test covers the render-only-column case. No table framework, sorting engine, or pagination logic was added.
