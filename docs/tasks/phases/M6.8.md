## Behavior Implemented

- Cards: Supplier details (name, company, tel/fax, mobile, email, tax validity from/to, address), Banking (bank name, branch, account number, IBAN), Attachments, and a sticky Actions card with Add supplier / Save as draft.
- All text/email/address/bank fields are uncontrolled and never validated, read, persisted or reset (an entered value survives Add supplier).
- Only attachment captions gate Add supplier: a blank or whitespace caption shows the 3 s error flash (bolt icon) and no success; an entirely empty form shows the 2.6 s "Supplier added" flash. Flash timers are not cancelled.
- Attachments are click-only (the "drag and drop" copy is cosmetic, as in the prototype); each shows name, a required-caption input (red border while blank) and a remove button.
- Save as draft has no handler (`PROTOTYPE-NOOP(D2)`, registered).
- EN/AR copy taken from the prototype `T()` pairs; English-only placeholders (`+965 …`, `name@company.com`, `—`, `KW…`) stay literal.
