## Route and Navigation Contract

- Live route: `/home/work-centre/:section?/:child?`.
- Default: `/home/work-centre` selects General → Create a New Task and retains the URL.
- General order: Create a New Task, Tasks, Enquiry, Observations, Checklists, Snag Lists.
- Commercial order: Price Change, Promotions.
- General → Commercial selects Price Change; Commercial → General selects Create a New Task.
- Switching sections updates the URL; switching groups does not remember the prior section.
- Valid configured child links remain URL-driven. Invalid sections/children render the route-owned not-found state.
- `/home/work-centre/tasks/open` remains valid route parity. `/home/work-centre/create-task/legacy-create` is rejected.
