## Implemented scope

- Task Details: Task subject, Project Name, Project Category, Details, Task Scope, Priority, Severity, Start date, and End date / Target completion.
- Attachments: click selection, drag/drop, multiple files, metadata rows, download through a short-lived object URL, and remove. The file input exposes the prototype format hint, but runtime intentionally does not enforce extension, MIME, size, or duplicate restrictions.
- Location and Zone: Location, Zone, Area, Sub-area, counter, Add, inline rows, and Remove. Add succeeds when either Location or Zone is present; no drawer, cascades, validation summary, Add Another, or Edit exists.
- Asset / Machine Information: Asset Category, Asset Name, Asset Code, and exact Asset Code placeholder.
- Task Classification: Category, Task Type, Risk / Impacted Category, Impacted Area, Touchpoint, and Guest Satisfaction KPI.
- Assignment Details: Process Owner single-select and Matrix Partner add/remove chips. There is no team suggestion behavior.
- Requester Information: fixed requested timestamp, Requested By `Tom Baker`, editable Requester Type / Role defaulting to `Manager`, Requester Department `Operations`, and zero-day elapsed display. No user API or auto-fill service exists.
- Reference Numbers: Enquiry, Observation, Incident, and read-only Source `Generic`.
- QR: modal, camera-viewfinder simulation copy, Simulate Scan, close, and Enter Manually. Simulation populates only `AST-<year>-<1000..9999>` Asset Code. No camera, registry, lookup, or location fill exists.
- Create accepts a completely empty form, displays inline `Task created`, keeps the form visible and populated, and prepends a minimal record to the M8.1 store. Cancel resets local form state. Save Draft and Clear controls are not present.

## Created-task mapping

- `id`: `TASK-` plus the last six digits of `Date.now()`.
- `subject`: entered subject, otherwise `Untitled task`.
- `kind`: current Task Scope; default `internal`.
- `flow`: `multi`.
- `stage`: `Open`.
- `risk` / `severity`: current segmented values converted to title case; both default `Medium`.
- `department`: `Operations`; `days`: `0`; `dependencies`: `0`; `due`: empty; `sla`: empty.
- `location` / `zone`: first added inline row, falling back to the current unadded values.
- Form-only values, requester data, dates, references, Process Owner/Matrix Partners, and attachments are not invented on the minimal M8.1 `Task` contract.
- New records are session-memory only, appear first in List/Board through the existing store, and disappear on reload. The original ten M8.1 fixtures are unchanged.
