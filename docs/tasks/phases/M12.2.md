### Production, security, and resilience audit

- Production source maps are explicitly disabled. Development locale helpers
  and error logging remain guarded by `import.meta.env.DEV`; no development
  mock server, developer-only URL, client secret, `eval`, `new Function`,
  unsafe HTML injection, or unsafe new-tab link was found in production source.
- D17 is implemented as BrowserRouter plus an external SPA rewrite, with hash
  routing documented as the fallback. A `/portal/ihub` build emitted only
  `/portal/ihub/assets/...` URLs; a cold deep link and refresh both passed in
  the production preview with no console warning/error.
- Route and application error boundaries, unknown-route handling, invalid task
  handling, and reload recovery remain covered. Browser drills returned the
  safe `Task not found` and `Page not found` surfaces. Controlled route and
  catastrophic failures remain covered by their focused tests.
- Intentional storage keys are `ihub.v2.preferences`,
  `ihub.v2.taskdash.config`, and `ihub.v2.settings.dashboardConfig`. Malformed
  or stale content falls back to sanitized defaults, including unknown widget
  IDs and locale/theme preferences.
